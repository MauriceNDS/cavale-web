# Cavale Web

Frontend for **Cavale** — the ultra-trail training companion.

React 19 · TypeScript · Vite · Tailwind 4 · TanStack Router/Query · Zod

```bash
npm install
npm run dev     # :5173, proxies /api → localhost:8080 (run cavale-api first)
```

Part of the [cavale](https://github.com/MauriceNDS/cavale) meta-repo. See
[CLAUDE.md](CLAUDE.md) for conventions.
